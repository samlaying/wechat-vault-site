AI生图越修越脏？试试这套“洗图”流程

AI 生图最让人头疼的，往往不是第一张不够好，而是后面越改越乱。

想换件衣服，脸变了；想修一下手，人物姿势又跑了。连续改几次，画面里开始出现噪点，发丝像乱码，衣服和皮肤也混在一起。

这时继续在原图上小修小补，通常很难真正解决问题。每次修改，AI 都可能重新理解整张图。你说“只改手”，它未必只改手。

这篇文章介绍一套比较实用的“洗图”方法。这里的“洗图”不是去水印，也不是规避版权，而是对自己生成或获得授权的图片进行结构整理、风格统一和重新生成。做法是把一张已经变乱的图拆开处理：先整理结构，再提取风格，最后按需要局部修复或重新生成。

处理他人作品、人物照片或商业素材时，先确认使用授权。

!图片预览

这套流程适合支持多图参考、图像权重、结构控制或局部蒙版的 AI

生图工具。不同工具的按钮名称可能不同，但只要能分别提供“外观参考”和“结构参考”，就可以按这个思路操作。只支持单张参考图的工具，需要先把 A 和 C

排成一张标注清楚的参考板，或者分阶段生成，不能指望它自动理解两张图的分工。

先把三张图分清楚

为了方便说明，先给图片编号。

A：原始参考图

A 主要提供人物和视觉风格，比如脸部特征、发型、服装气质、色彩和绘画方式。

B：待修复图

B 是当前已经变脏、变形，或者需要重新生成的图片。它可能还保留着值得参考的动作和构图，也可能已经偏得比较严重。

C：白膜图

C 是根据 B

整理出的结构参考图。本文所说的“白膜图”不是行业统一格式，也不一定非要纯白或灰模人物；它指一张简化后的结构参考图，重点呈现人物位置、姿势关系、画面比例、镜头角度和空间布局，尽量减少颜色、噪点和错误细节。

可以先这样记：A 负责“人物和风格”，C 负责“结构和动作”。B 是问题的来源，也是生成 C、分析偏差的依据。A

可以是同一人物的原始图，也可以只是风格或人物参考；如果 A 和 B 不是同一个人物，要在提示词里说明最终人物身份以哪张图为准。

第一步：从 B 整理一张白膜图

把待修复图 B 上传给 AI，让它先整理画面结构。

可以使用这段提示词：

123456789

请根据这张待修复图片生成一张干净的结构参考图，也可以理解为白膜图。

参考原图的人物姿态、整体构图、镜头角度、空间关系、身体比例和主要轮廓，

尽量保留动作方向与画面布局；如果原图的姿势或比例明显有问题，可以做小幅、自然的调整。

弱化原图中的脏乱颜色、噪点、错误纹理和复杂装饰，

不要增加其他人物或无关物体，不要把白膜图做成一张带有复杂材质的成片。

画面简洁、结构清晰，适合作为后续重新生成图片时的构图参考。

这一步不需要追求画面好看，先把需要保留的构图、姿势和空间关系整理出来就够了。比如原图是蹲姿，白膜图要保留蹲姿；原图是三分之二侧身，也不要无故变成正面站立。只要动作关系和构图成立，颜色简单一点没有关系。

生成 C 后不要直接进入下一步，先按下面的检查项看一遍。

白膜图也要检查：它不是动作锁定图

这里有一个容易误解的地方：白膜图不是把人物动作完全锁死的控制图。

它只是把构图、姿势和空间关系单独提取出来，方便后面重新生成。如果白膜图本身继承了原图的错误动作，比如手臂比例不对、重心不自然、轮廓变形，直接拿它继续生成，反而可能把这些问题带到结果里。

所以，白膜图生成后要先检查一遍：

  • 姿势是否自然；
  • 手脚和肢体比例是否正常；
  • 人物重心是否合理；
  • 构图中是否有本来就不想保留的部分。

发现问题后，可以先调整白膜图，再进入后面的重组流程。这里的“调整”不是把它重新画得很精细，而是修正结构即可。颜色、材质和风格仍然应该保持简化。

一张合格的

C，缩小看时应该能回答四个问题：人物在画面哪里，身体朝向哪里，动作关系是什么，镜头和留白怎样安排。它不需要有漂亮的脸、清晰的发丝或完整的衣服纹理。只要这些结构信息还看得出来，就已经完成任务；如果画面里仍然有大量颜色、材质和装饰，说明它还不够简化。

改原图和改白膜图，有什么区别？

两者处理的问题不一样。

需要处理的问题 | 更适合修改

---|---

脸部、发丝、颜色、材质等细节 | 原图

姿势、人物位置、镜头和构图 | 白膜图

原图已经被多次修改，画面很脏 | 重新生成白膜图

原图动作本身就不自然 | 先调整白膜图

比如，人物脸部已经比较稳定，只是手指画错了，可以直接修原图；但如果人物的重心、手臂角度或整体姿势都有问题，就不建议继续在原图上补，先处理白膜图更合适。

可以先这样记：

原图局部仍然干净时，适合修细节；结构有问题时，先调整白膜图。

这不是绝对规则。如果原图已经严重变脏，脸部、发丝等细节也未必适合直接修；可以先从较干净的参考重新生成，再处理细节。白膜图也只是参考，最终生成时仍要按需要调整它的影响。如果工具提供“参考强度”“图像权重”或“结构控制”等设置，希望大致保留原动作时，可以提高

C 的影响；如果没有这类设置，就在提示词里写明“参考 C 的结构，但允许调整动作”。想明显改变动作时，也可以先把白膜图改成新的姿势。

因此，白膜图步骤更准确的说法是：

12345

从待修复图提取结构

↓

检查并修正白膜图

↓

用整理后的白膜图辅助重新生成

这样处理，比直接把白膜图当成“必须完全遵守的动作模板”更灵活，也更不容易把原图的问题带到最终结果里。

第二步：用 A 和 B 反推 Prompt

白膜图解决了结构问题，但它不一定保留原图的风格。这时可以让 AI 同时分析 A 和 B：A 用来提取人物与风格，B

用来帮助判断当前画面的动作、布局和问题位置。

这里的 B 只提供仍然有用的信息。比如 B 里的主体位置和镜头还准确，就保留这些；如果 B 的手臂比例、脸部轮廓或身体连接已经错了，就不要把错误也写进

Prompt，后面以检查并修正后的 C 为准。

提示词可以这样写：

12345678910

请同时分析参考图 A 和待修复图 B，并反推出一组可直接用于 AI 生图的中文提示词。

请分别提取：

  1. 参考图 A 中的人物特征、脸部气质、发型、服装风格和整体色彩；
  2. 参考图 A 中的绘画方式、笔触、材质、光影和画面氛围；
  3. 待修复图 B 中的构图、人物姿态、镜头角度和空间关系；
  4. B 中已经出现的变形、噪点、错误纹理和需要避免的问题。

请尽量使用具体的对象、材质和光线描述，少用空泛的形容词。

最后整理成一份可以直接复制使用的组合提示词。

如果 A 和 B 不是同一个人物，可以在提示词最后补一句：

12

最终人物身份、脸部特征和发型以参考图 A 为准；

待修复图 B 只用于分析构图和动作，不要复制 B 的人物脸部、服装或其他外观。

描述越具体，后面越容易控制。比如“很有科技感”可以改成“白色机能外套、银色机械义肢、黑色战术织带”；“画面很干净”可以改成“纯白无缝背景、影棚柔光、边缘清晰、自然投影”。

!图片预览

第三步：用 A 和 C 交叉重组

有了风格 Prompt 和白膜图，就可以重新组合。

这一轮建议使用 A 加 C，而不是继续把已经变脏的 B 当作主要参考。A 提供人物、服装、色彩和视觉风格；C 提供结构、动作、镜头和主体位置。B

主要用于前面的分析和提取信息，通常不再作为最终生成的主要参考，以免把已经出现的脏污和错误纹理带进去。

这里的“交叉重组”主要是整理参考图的分工和

Prompt，不一定要额外生成一张中间图。如果结构比较复杂，可以先做一张测试图，检查人物和构图是否接得上，再生成最终版本。

示例：

123456789

以参考图 A 中的人物特征、脸部气质、发型、服装和整体风格为基础，

按照白膜图 C 中的构图、人物姿态、镜头角度和空间关系重新生成。

保留 A 的人物与未来科技插画风格，保留白色机能外套、黑色战术织带、

银色机械结构和纯白影棚背景。参考 C 的动作和画面布局，

允许对手部、比例和局部动作做自然的小幅调整，不要生成灰色白膜效果。

皮肤细腻，发丝清晰，金属部分有明确的镀铬质感，

人物比例稳定，背景干净，避免明显噪点和错误纹理。

这里最容易写反的是两张图的分工。可以记成：A 告诉 AI 人物应该长什么样，C 告诉 AI 人物应该怎么摆。

!图片预览

第四步：重新生成，再做一次检查

最终输入通常由三部分组成：原始参考图 A、白膜图 C，以及第三步整理好的组合 Prompt。是否还要带上 B，取决于工具和图片状况；如果 B

已经明显变脏或变形，不要把它当作主要参考。若工具支持局部蒙版或区域重绘，而问题只是一个小瑕疵，可以直接修那一小块，不必整张重做。

如果要换掉某个重要元素，最好补一张对应的参考图。比如换服装，可以提供服装参考；想重做机械手臂，可以提供机械结构图。只写一句“换成某某款式”，模型通常只能抓到一个大概。

还可以补充一些约束：

1234

保持人物结构和身体比例稳定，保持整体构图和动作关系，不要改变脸部特征。

不要出现多余人物、手指变形、肢体错位、发丝乱码、服装融化、

五官模糊、背景杂乱和明显噪点。

这些限制不能保证一次成功，但能减少常见错误。生成后先看整体构图，再看人物比例、脸、手、服装边缘和背景纹理，不要只盯着脸部判断好坏。

!图片预览

用这组图判断是否做对

可以把本文的案例当成一次完整演练：B 是已经出现漂移和细节污染的待修复图；第一步生成 C

时，只看人物位置、动作、镜头和留白，不追求颜色；检查后，如果手臂比例或重心不对，先在 C 上修正；第二步再用 A 和 B

提取人物、服装、材质与光线描述，但把 B 中已经确认的错误排除；第三步用 A 加整理后的 C 做测试生成；最后再根据测试结果调整 Prompt 或参考强度。

判断结果时，不要只问“像不像原图”。可以按这个顺序看：

  1. 先看主体有没有回到正确位置，动作和镜头是否成立；
  2. 再看人物身份、服装风格和色彩是否接近 A；
  3. 最后看手部、发丝、材质和背景有没有新的噪点。

如果第一项就错了，回到 C；如果前两项都对，只是局部细节有问题，优先用蒙版或局部重绘。这样才能判断到底是哪一层输入出了问题，而不是笼统地重新生成整张图。

为什么不建议一直修改同一张图？

因为很多 AI 生图工具并不是严格的 Photoshop

图层编辑。支持蒙版或区域重绘时，局部问题可以先局部处理；当人物结构、构图或整体风格已经漂移，才更适合重新整理白膜图并整图生成。

你说“只改衣服”，模型可能顺便重画脸；你说“修手部”，它可能改变手臂长度；你说“换背景”，人物的位置也可能跟着变化。

当一张图被连续修改多次，常见结果就是人脸越来越不像、发丝和衣服细节越来越乱，手脚开始变形，背景不断增加无关元素，构图也慢慢偏离最初版本。

发现画面已经明显跑偏时，先判断偏差来自哪里：如果 B 的动作和构图仍可用，就从 B 重新整理 C；如果 B 的结构本身也错了，就把 B

当作问题线索而不是必须服从的模板，直接修正 C，必要时用草图或文字重新设定动作，再走后面的流程。

最后记住这几句话

白膜图只需要交代清楚姿势、构图和轮廓，不需要成为最终效果图。

反推 Prompt 时，多写具体对象、材质和光线，少写只有情绪、没有画面信息的词。

交叉重组时，明确 A 管外观，C 管结构。发现漂移后，先判断它是外观问题还是结构问题，再回到对应的输入继续改。

这套方法做的事情很朴素：把一张已经混乱的图片拆成“结构”和“风格”两个问题分别处理。重新生成时，AI

不必从一团脏细节里猜你的意图，画面也更容易回到可控状态。
