有人用 REA 逆向了 Claude 桌面端！30 个教科书级别的 React 组件全部开源

人，进来学交互了

REA 是最近国内外开发者都为之疯狂的一个项目，10 月 刚上GitHub，目前就已经 25 万星了。它的口号是 “逆向一切” ，把 AI接进去就能看到软件咋做的，一项一项拆出来。

推友 Caho1 用 REA 就 把Claude desktop app给拆了 ，之后用 TypeScript + Tailwind把核心交互逻辑手写还原成了 30 个独立的 React 组件文件。还写了一份 3000 多行的设计分析手册。

不看不知道，原来平时 Claude那些用起来温润舒适的体验，背后都是设计上的 极致工程化 ……感觉这一个项目就够学好久了，比起四拼八凑找动效网站抄动效有用得多。这个仓库不仅给了你 React 组件，还讲明白了设计和体感之间的那根牵着的逻辑。

拆出来的东西比组件更有意思

30 个组件是真的实用。但逆向手册里真正有价值的，是 Anthropic 藏在代码里的 那些设计决策 。挑几个说。

滚动边缘渐隐。 长对话列表顶部和底部的文字不会硬切消失，有一层 7 档非线性透明度遮罩。7 个采样点的 Alpha 分布近似 y≈x^1.5幂律曲线，比线性渐变柔和得多，高分屏上也不会出现色阶断层。

拖卡片会微微歪。 拖附件的时候有 4px 死区防误触，进入拖拽后卡片根据鼠标移动方向产生最大 3.5°的倾斜角。刚好是纸张被指尖捏起来的角度。

滚屏不抢你正在读的。 AI 聊天界面最抓狂的时刻：模型正在吐字，你往上滚想看看前面的代码，页面立刻把你拽回最底部。Claude 的做法是150ms 冷却机制。检测到你主动向上滚动，系统锁定自动滚屏 150ms，加上 40px 的底部容差。不会在你阅读的时候抢屏幕。代码在useClaudeScrollPinning.ts。

中文回车不误发。 用拼音打字，按回车确认候选词的时候消息直接飞出去。几乎所有 AI 聊天界面都有这个 bug。Claude 用了双重守卫!(e.nativeEvent.isComposing || e.keyCode === 229)，输入法组合状态下回车不触发发送。还拦住了 Escape冒泡，关候选词不会顺带关掉整个对话窗。

弹簧只弹一次。 很多 UI 的弹簧动效做出来像果冻，晃三晃才停。Claude 的弹簧参数是stiffness=380、damping=32、mass=1.0，正好落在临界阻尼点，超调量压到 0.5% 以内。有重量感，但一次到位。

提示音是代码合成的。 发送消息那声轻响没有音频文件。Claude 直接调 Web Audio API 的振荡器，正弦波混三角波，合成C5+E5 双音和弦，音量锁定 30%，15ms 淡入、120ms 淡出。零外部依赖，也消除了音频启停时的爆音。代码在ClaudeAudioPlayer.ts。

0.5% 超调量、3.5° 倾角、150ms 冷却、30% 音量。每一个都是在"刚好对"和"过了"之间调出来的数字。

几个值得直接搬走的

ChatComposer + RichComposerWithMentions ：Claude 的输入框。自适应高度伸缩，三态阴影（空 /有内容 / 聚焦），自带 CJK 输入法守卫、/ 指令触发和 @ 上下文提及。做 AI 聊天应用的可以直接替换你现有的输入组件。

ModelSwitcherWithTokenGauge ：模型选择器，带一个 SVG 四色环形仪表盘，一眼看到input、output、cache read、cache write 各占多少上下文窗口。做 AI 工具的话，这个组件的信息密度很高。

ThinkingAccordion + ReasoningAmbientGlow ：思考过程折叠面板，用 CSS Grid 的 0fr→1fr做弹性伸缩动画，模型还在生成的时候强制展开，生成完才允许折叠。配套的 ReasoningAmbientGlow是思考时卡片周围那层陶土色暖光漫反射，加上文字上的非对称扫光效果。

ScrollFadeContainer ：上面说的那个 7 档渐隐容器。不限于 AI 场景，任何长列表都能直接套上去用。

ClaudeMotionPresets ：四套生产级弹簧参数（Bouncy / Snappy / Gentle / Heavy Snap），配合 Framer Motion 直接用。不用自己调参了。

McpToolDecisionCard ：Agent 调用外部工具时的三态授权卡片（待批准 → 运行中 → 成功/失败）。做 agent应用的可以直接拿这套状态机。

LiveMicActivityBars ：语音模式的 6 频段实时波形柱。8% 噪声门限过滤掉空调底噪，0.7 次幂 Gamma压缩让人声细语和高分贝之间的动态范围很均匀。

MediaLightboxViewer + useClaudeSharedElementTransition ：点击缩略图展开灯箱时的共享元素转场。缩略图的位置、尺寸、圆角连续变形到全屏视图，缩放以鼠标光标为不动点，不会把你想看的细节推出画面。

useRateLimitBackoff ：429/503 限流时的指数退避 Hook，带 20% 随机抖动和 3 次自动熔断。调 API的项目都需要这个。

怎么用

先看效果。 clone 下来，浏览器双击打开 Storybook.html ，不需要 Node.js：

BASH git clone https://github.com/Caho1/open-claude-ui.git open open-claude-ui/docs/claude-components-storybook.html

所有组件的动效、主题切换、交互反馈都能在storybook.html里直接体验。看中哪个再去拿源码。

拿组件。 code-examples/ 目录下 30 个独立 .tsx 文件，配合 cds-theme.css 和tailwind.config.js 使用。每个文件零耦合，看中哪个拷哪个。

喂给 AI 编程助手。 仓库自带 AGENTS.md 和 CLAUDE.md，丢进你项目的上下文，Cursor 和 Claude Code就能按这套设计规范写新组件。

30 个组件一览

● 基础控件 ：CdsButton、SegmentedControl、StatusIndicators、ConfirmationDialog、AttachmentCard

● 会话与输入 ：ChatComposer、ChatMessageBubbles、ThinkingAccordion、RichComposerWithMentions、ModelSwitcherWithTokenGauge、McpToolDecisionCard

● 动效与光效 ：ClaudeMotionPresets、ReasoningAmbientGlow、ScrollFadeContainer

● 视听与媒体 ：ClaudeAudioPlayer、LiveMicActivityBars、MediaLightboxViewer、CodeBlock、StreamingDiffViewer

● 交互物理 ：ArtifactsSplitPaneResizer、EpitaxyIframeBridge、useClaudeSharedElementTransition

● 桌面与协作 ：createClaudeMainWindow、ClaudeDesktopHeader、DraggableSessionList、CoworkAgentCanvas

● 工程 Hooks ：useClaudeScrollPinning、useClaudeRovingFocus、useRateLimitBackoff、ContainerResponsiveBar

逆向手册全文在仓库的 docs/Claude Design System (CDS).md，七大章节 31 小节，从设计哲学到每一个关键帧参数都有反编译取证位置。
